Links
=====

Allowed: https (https://coral.example/terms), http (http://coral.example/plain), email (help@coral.example?subject=Card%20terms), phone (+18005550100).

Normalized: scheme case (https://Coral.Example/Terms), trimmed (https://coral.example/trim), accent (https://coral.example/caf%C3%A9?q=%C3%A9), mailto case (Help@Coral.Example).

Refused, text stays: script, relative, no scheme, ftp, data, empty.

Refused: space, user info, international host, backslash, bare tel.

One link in three runs: read the rewards rules (https://coral.example/rewards).

A link across a break: line one
line two (https://coral.example/a).

A variable that is a link: coral.example (https://coral.example/site).
