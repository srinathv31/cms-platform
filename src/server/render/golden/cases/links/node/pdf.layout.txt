# Links
Allowed: https, http, email, phone.

Normalized: scheme case, trimmed, accent, mailto case.

Refused, text stays: script, relative, no scheme, ftp, data, empty.

Refused: space, user info, international host, backslash, bare tel.

One link in three runs: read the rewards rules.

A link across a break: line one
line two.

https://coral.example/privacy and coral.example and help@coral.example show no address twice.

A variable that is a link: coral.example.
